# ۰۰ — وضعیت Migration (به‌روز: commit انتهایی این branch)

> **خلاصه‌ی صادقانه:** Migration **کامل نیست**. زیرساخت، منطق هسته و Design System ساخته و اثبات شده؛ **هیچ صفحه‌ای هنوز در Flutter نیست** و APK Flutter هنوز ساخته نشده. نسخه‌ی منتشرشده‌ی HTML/Capacitor دست‌نخورده است.

## انجام‌شده و اثبات‌شده
| مورد | شواهد |

| Design System (توکن‌ها + تم Flutter) | پیش‌نمایش + ۴۸ تست (کنتراست WCAG در دو تم) |

## انجام‌نشده (به ترتیب اجرا)
1. **لایه‌ی ذخیره:** `AppStore`، نوشتن اتمیک، `rpNormalizeState`، `migrateTargetSnapshots`.
2. **Backup/Restore:** JSON نسخه‌ی ۳٫۰ + رمزنگاری AES-GCM/PBKDF2 (تست cross-implementation با فایل‌های تولیدشده‌ی JS).
3. **Pro/پرداخت:** `computeProWindow`، ساعت مطمئن، `rpSig`، کلاس Kotlin بازار به‌صورت MethodChannel.
4. **Data Migration واقعی** (۳ لایه‌ی `03-DATA-MIGRATION.md`) — *لایه ۱ نیازمند تأیید تو (نسخه‌ی پل HTML)*.
5. **نوتیفیکیشن** (`flutter_local_notifications`)، **Back اندروید**، **ذخیره در Downloads**.
6. **همه‌ی صفحه‌ها و Modalها** (۱۰ صفحه + ۲۳ Modal) روی Design System.
7. **آواتار** (رندر لایه‌ای، تنفس، روز/شب، فروشگاه/کمد)، **نمودارها** (دایره‌ای + میله‌ای)، **PDF/CSV**.
8. ضبط/پخش صدا، عکس‌ها، آموزش اولیه/راهنما/قوانین، تحلیل هوشمند.
9. CI `build-flutter.yml`، و تست‌های Android/Regression روی گوشی.

## آنچه در این محیط **نمی‌شود** تأیید کرد
- **ساخت APK و اجرا روی دستگاه:** Android SDK از `dl.google.com` می‌آید و مسدود است. ساخت باید در GitHub Actions انجام شود و تست روی گوشی با خودِ توست.
- **انتقال داده از WebView واقعی** (لایه ۲) و **پخش صدای قدیمی webm/opus** فقط روی گوشی قابل تأیید است.

## خطرهای شناخته‌شده
- حجم کار: ~۱۵٬۳۰۰ خط JS، ۵۳۶ عنصر، ۲۳ Modal. هر ماژول باید با تست هم‌ارزی بسته شود؛ عجله = رگرسیون.
- خطاهای خاموش رایج در این نوع پورت: رفتار `slice`/`substring`، `typeof` آرایه، گرد کردن نیم، ترتیب کلیدها — هرکدام دست‌کم یک‌بار در همین دو ماژول دیده شد.
