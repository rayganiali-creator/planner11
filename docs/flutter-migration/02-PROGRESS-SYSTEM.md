# سیستم پیشرفت (Progress / Achievement / Badge) — جایگزینِ سکه، آواتار و فروشگاه

> Do → Improve → Achieve → Earn Badge → Build Your Progress Identity
> هیچ ارز، خرج‌کردن، فروشگاه، آواتار، HP/Boss، Loot یا پاداشِ تصادفی وجود ندارد.

## معماری
```
Activity (داده‌ی واقعی) → XPEvent → XP → Level → Rank
Real activity → Achievement → Badge → Collection (+ Featured)
Achievement → Milestone ، Achievement/Progress → Title
```
کد در `lib/core/progress/` (خالص و تست‌پذیر) و رابط در `lib/features/progress/`:

| فایل | کار |
|---|---|
| `config.dart` | همه‌ی عددها: XP هر منبع، سقف‌ها، منحنی سطح (۱..۱۰۰)، ۹ رتبه، پیکربندی آمار |
| `ledger.dart` | دفتر XP در `state['progress']` (رویدادها، unlocked، عنوان، ویژه‌ها، فصل‌ها، announced) |
| `sources.dart` | تبدیل داده‌ی واقعی به رویدادهای XP با **شناسه‌ی قطعی** |
| `engine.dart` | `syncProgress` (idempotent)، سطح/رتبه، دستاوردها، فصل، Pending announcements |
| `achievements.dart` | کاتالوگ داده‌محور (۳۴ دستاورد/نشان، ۱۰ عنوان، ۱۲ نقطه‌ی عطف) و متریک‌ها |
| `stats.dart` | آمار با فرمول‌های مرکزی (`statFormulas`) و null در نبودِ داده |
| `features/progress/badge_emblem.dart` | نشانِ هندسیِ خطی (CustomPainter) با `BadgeTokens` وابسته به تم |

## XP (فقط از فعالیت واقعی)
| منبع | XP | شرط اعتبار |
|---|---|---|
| عادت | ۱۰ (مهم/دشوار ۱۵) | عادتِ سررسید و موفق در همان روز؛ سقف ۱۵۰ XP در روز |
| کار | ۸ (مهم ۱۲) | حداقل ۱ دقیقه بعد از ساخت، عنوان ≥ ۳ حرف، عنوانِ تکراری در یک روز فقط یک بار، سقف ۱۲ کار در روز |
| چالش | ۲۵ تا ۱۰۰ (بر اساس مدت/هدف) | موفق + حداقل ۱ ساعت از ساخت؛ سقف ۱۰۰ XP در روز |
| پومودورو | ۱۰/۱۲/۱۵/۲۰ (۱۰/۳۰/۴۵/۶۰ دقیقه) | فقط پایانِ واقعیِ فازِ تمرکز (≥ ۱۰ دقیقه)؛ سقف ۱۲ جلسه در روز |
| مطالعه | ۵ تا ۱۵ | فقط **صفحه‌ی تازه** نسبت به بیشینه‌ی قبلیِ همان کتاب؛ سقف ۳۰ XP در روز |
| مرور روزانه | ۱۰ | یادداشتِ ≥ ۲۰ حرف؛ روزی یک بار |
| تکمیل روزانه | ۱۰ | ≥ ۲ عادتِ سررسید و ≥ ۸۰٪ انجام |
| استمرار | ۲۵ / ۱۰۰ / ۳۰۰ | یک بار برای ۷/۳۰/۱۰۰ روز؛ هرگز ابطال نمی‌شود |

### ضدِ تقلب
* هر رویداد شناسه‌ی قطعی دارد (`habit:{id}:{date}`، `todo:{logId}`، `lib:{book}:{date}` …) ⇒ Complete→Undo→Complete، Refresh و Restart هیچ XPِ اضافه نمی‌سازند.
* Undo رویدادِ قابل‌ابطال (عادت/کار/تکمیل روزانه) را `revoked` می‌کند؛ انجامِ دوباره **همان** رویداد را برمی‌گرداند.
* تاریخِ قدیمی (بیش از ۳ روز) و آینده نمی‌تواند XPِ تازه بسازد (مهاجرتِ اولیه استثناست).
* حذفِ عادت/کار/چالش XPِ کسب‌شده را نمی‌سوزاند، ولی ساختنِ دوباره هم XP تازه نمی‌دهد.
* شکستنِ استریک هرگز XP/سطح/نشان را حذف نمی‌کند؛ نشان‌ها و عنوان‌های بازشده دائمی‌اند.

## سطح و رتبه
`xpToAdvance(n) = round10(100 + 2·n^1.6)` ⇒ سطح ۱۰ ≈ ۱٫۹k XP، سطح ۵۰ ≈ ۳۵k، سطح ۱۰۰ ≈ ۱۳۰k. رتبه‌ها: نوآموز، آغازگر، متمرکز، مستمر، منضبط، متعهد، برجسته، استاد، استاد اعظم (از سطح ۱/۵/۱۲/۲۲/۳۵/۴۸/۶۲/۷۸/۹۲).

## آمار (۳۰ روز اخیر؛ پرو: دوره‌ی قبل + تغییر)
فرمول‌ها در `stats.dart → statFormulas` و در رابط (آیکن i) نمایش داده می‌شوند. بدونِ داده‌ی کافی: «داده کافی برای محاسبه وجود ندارد.»

## Free / Pro
* **Free**: XP، سطح، رتبه، همه‌ی دستاوردها/نشان‌های اصلی، نقاط عطف، عنوان‌ها، استریک، آمار پایه، مجموعه‌ی نشان‌ها (فیلتر دسته + مرتب‌سازی پایه)، نشان‌های ویژه، صفحه‌ی پیشرفت.
* **Pro**: آمار پیشرفته (مقایسه و تغییر)، تاریخچه‌ی XP، فیلتر/مرتب‌سازی پیشرفته (وضعیت، Tier، کمیاب‌ترین)، فصل‌ها (۳۰/۶۰/۹۰ روزه با XP فصلی جدا و بایگانی؛ نشان‌های فصلی)، حلقه‌ی Premium روی نشان‌ها.
* دستاورد اصلی هرگز Paywall نمی‌شود.

## داده، Backup، مهاجرت
* همه چیز Local در `state['progress']` + `todoLog` + `pomodoro.log` ⇒ همراه Backup/Restore (کلیدهای `progress`, `todoLog`).
* مهاجرت: اولین `syncProgress` تاریخچه‌ی واقعی را (با سقف‌ها) به XP/دستاورد تبدیل می‌کند؛ **سکه به XP تبدیل نمی‌شود** (فقط ثبتِ اطلاعاتی در `progress.legacy`)؛ آواتار/انبار نمایش داده نمی‌شود (داده‌ی خام حذف نمی‌شود)؛ انیمیشنِ جعلی ساخته نمی‌شود.
* افزودنِ دستاوردِ تازه: یک خط به `achievementCatalog`.
