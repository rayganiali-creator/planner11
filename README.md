# روتین پلنر — نسخه‌ی اندرویدِ نیتیو (با Capacitor)

این پوشه یک اپ اندرویدِ واقعی (نه فقط PWA) از برنامه‌ی روتین پلنر است. تفاوت اصلی‌اش با
نسخه‌ی PWA این است که یادآوری‌ها (کارهای دارای زمان و ریمایندر عادت‌ها) مستقیماً به
**AlarmManager خودِ اندروید** سپرده می‌شوند؛ یعنی حتی اگر برنامه کاملاً بسته باشد یا گوشی
ری‌استارت شده باشد، دقیقاً سرِ همان زمانِ تعیین‌شده نوتیف می‌رسد.

فایل‌های اصلیِ برنامه (رابط کاربری) داخل پوشه‌ی `www/` هستند — همان `index.html` که قبلاً
داشتی، به‌علاوه‌ی کدهایی که وقتی داخل اپ نیتیو اجرا می‌شود، به‌جای نوتیفیکیشن وب از
افزونه‌ی `@capacitor/local-notifications` استفاده می‌کند.

## ساخت فایل APK (بدون نیاز به نصب Android Studio)

چون ساخت واقعیِ اپلیکیشن اندروید به Android SDK نیاز دارد که نصبش روی خیلی از سیستم‌ها
وقت‌گیره، این پروژه یک **GitHub Action** آماده دارد (`.github/workflows/build-android.yml`)
که APK را به‌صورت خودکار روی سرورهای گیت‌هاب می‌سازد.

### مراحل:

1. یک مخزن (repository) جدید و **خصوصی یا عمومی** روی GitHub بساز.
2. تمام محتوای همین پوشه (`routine-planner-capacitor`) را داخل آن مخزن push کن:
   ```bash
   cd routine-planner-capacitor
   git init
   git add .
   git commit -m "اولین نسخه"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO.git
   git push -u origin main
   ```
3. برو به تب **Actions** توی صفحه‌ی مخزن روی گیت‌هاب. یک workflow به اسم
   «Build Android APK» به‌صورت خودکار اجرا می‌شود (چون به شاخه‌ی `main` پوش کردی).
   اگر خودش اجرا نشد، می‌تونی دستی از همون تب Actions روی «Run workflow» بزنی.
4. صبر کن تا سبز بشه (چند دقیقه طول می‌کشه).
5. روی همون اجرای موفق کلیک کن، پایین صفحه بخش **Artifacts** یک فایل به اسم
   `routine-planner-debug-apk` می‌بینی — دانلودش کن، داخلش `app-debug.apk` هست.
6. فایل `app-debug.apk` رو بفرست روی گوشی اندرویدت و نصبش کن (چون از گیت‌هاب و نه از
   Play Store هست، لازمه یک‌بار اجازه‌ی «نصب از منابع ناشناس» رو به مرورگر/فایل‌منیجرت بدی).

⚠️ این یک APK از نوع «debug» است (برای تست شخصی خودت کاملاً کافیه). اگر بعداً خواستی آن را
در Google Play منتشر کنی، باید نسخه‌ی امضاشده (`release`) با کلید امضای خودت بسازی — این
بخش جداست و در صورت نیاز می‌تونم راهنماییت کنم.

## اگر خواستی خودِ برنامه (ظاهر/امکانات) رو تغییر بدی

فایل اصلی که باید ویرایش کنی `www/index.html` است. بعد از هر تغییر، این دستورها را بزن تا
پوشه‌ی اندروید هم به‌روز شود، بعد دوباره push کن تا GitHub Action نسخه‌ی جدید APK را بسازد:
```bash
npm install      # فقط بار اول
npx cap sync android
git add .
git commit -m "به‌روزرسانی"
git push
```

## نکته‌ی مهم درباره‌ی نسخه‌ی PWA (مرورگر)

همین کدِ `www/index.html` وقتی داخل مرورگر (نه اپ نیتیو) باز بشه، دقیقاً مثل قبل به‌عنوان
یک PWA کار می‌کند (با Service Worker و نوتیفیکیشن وب که قبلاً فیکس کردیم). یعنی می‌تونی
همین فایل‌ها رو هم روی GitHub Pages میزبانی کنی (برای نسخه‌ی وب/PWA) و هم با همین پروژه‌ی
Capacitor یک APK واقعی بسازی — هر دو از یک کدِ مشترک.
